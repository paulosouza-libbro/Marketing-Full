# Libbro Marketing App

Agência de marketing autônoma da Libbro. Agentes de IA executam todo o processo — Paulo dá o briefing, aprova o conteúdo, e os agentes cuidam do resto.

## Agentes
- Diretor, Pesquisador, Estrategista, Copywriter, Designer, Produtor de Vídeo, SEO/YouTube, Social Media, Growth, Analista

## Fluxo
Briefing → Diretor → Equipe executa → Aprovação → Publicação → Análise → Sugestões

## Stack
- Backend: Python + CrewAI
- Frontend: Next.js
- Cloud: Railway/Render
